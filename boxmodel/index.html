¿Qué es el modelo de caja?

El modelo de caja es una estructura de CSS que permite controlar el tamaño, el espacio y los bordes de los elementos de una página web.

1. Content

Es el contenido principal de la caja, como texto, imágenes o información.

2. Padding

Es el espacio interior entre el contenido y el borde.

3. Border

Es la línea que rodea el contenido y el relleno.

4. Margin

Es el espacio exterior que separa una caja de otras.
